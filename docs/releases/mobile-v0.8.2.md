# Plainva Mobile 0.8.2

Pick up where you left off, move through your calendar with a swipe, and jump straight to a heading. This release also strengthens sync, account connections and the handling of comments and suggestions on your phone.

- Your navigation, active tab and last database view return after a restart.
- The release highlights identify 0.8.2 even when TestFlight keeps its 1.0 marketing version, and appear once per new release.
- Tap the calendar title to choose a date, or swipe to move through the current calendar view. Date fields follow the app's language and week-start setting.
- Anchor links open the relevant heading. Backlinks show their individual locations, and typing `[[Note#` offers heading suggestions.
- Comments work in ordinary vaults, follow moved notes and show your name or device label. Interrupted suggestion decisions can resume; accepted changes reach the visible editor.
- Failed reads and downloads stay pending instead of being treated as successful sync. Offline edits survive queued renames, and incomplete server inventories are rejected.
- Sign-ins stay attached to the right account and vault. Google sign-in preserves the Gmail app password, and interrupted password changes can be resumed.
- Obsidian image embeds, daily-note formats and **Select all** behave more consistently. ZIP imports enforce size limits while unpacking and preserve existing files when names collide.

**Android:** Download the signed APK attached to this release. The AAB is included for distribution through Google Play; the new build is also uploaded to the internal test track.

**iPhone and iPad:** Join the [public TestFlight group](https://testflight.apple.com/join/ZRSEfZBn). TestFlight continues to show the existing **1.0** marketing version with a new build number; this coordinated build contains the 0.8.2 changes. There is no iOS installer attached to this GitHub release.

The GitHub **Pre-release** label keeps the desktop update channel separate; this Android release is publicly downloadable. Encrypted workspaces and native device calendars remain experimental. Section embeds are still a separate feature.
