# Plainva Mobile 0.8.6

Ticks from your provider arrive — on Android and iOS. This coordinated update includes the shared task, link, property, file and sync fixes since 0.8.5 and a round of wishes from testers, among them a choice of how links look.

If you sync a vault across devices, please update all of them (see *Sync* below).

- **The phone's database takes turns.** A write that met a sync step, an index pass or the calendar cache could fail after the file had already changed and lose its place in the sync queue; an editor then ended in a conflict copy of a note nobody else had touched. Transactions now wait for one another, and a queue entry that fails is made up for.
- **Ticks from your provider arrive.** A task ticked at Google, Microsoft or over CalDAV reaches its note; every task list is fetched on its own, and its problem stands above the task view. A due date is no longer lost where the database cannot hold it, a reminder keeps its time, and **Refresh** and a tick ask the provider at once. **Show tasks** puts due tasks into every calendar view, and a database's entries show in the day, 3-day and week views too. A saved event stays on screen ([#119](https://github.com/plainva/plainva/issues/119)).
- **Wishes from testers.** The all-day row stays pinned above the hours and shows five rows, then “+ n more”. **Show week numbers** works in every calendar, switched at the foot of each date picker. A new note opens to be written in, task boxes in a note and the journal are big enough for a finger, and **New task** and a database's date cell pick their day from the app's own calendar. How links look is a choice under **Settings → App → Appearance**: **Underlined** (the default, as before), **Tinted**, **Colour only** or **Subtle** for links to notes, **Underlined** or **Colour only** for links to the web.
- **Small things.** A tap into an open table cell places the caret ([#118](https://github.com/plainva/plainva/issues/118)); a jump from the outline puts the heading at the top, below the reader bar; search hits and a template's caret are centred; an embed in code stays text.
- **Markdown links, one destination.** A Markdown link leads to the same place on every surface of both shells — from the note's folder first, otherwise like a wiki link — and the phone now opens links to folders. Wiki links such as `[[_private_]]` count as links for backlinks, the graph and a rename. The **Overviews** screen offers to prepare a note it adopts, as the desktop does.
- **Sync.** An upload writes only over the version it expects: with WebDAV, S3, OneDrive and Dropbox, a write is refused when another device uploaded in between, and the next sync merges or keeps a conflict copy instead of overwriting that change. A note's own text is kept as a conflict copy beside an open conflict, and a file kept although the cloud deleted it goes up again; the notice about it names the file once. A device on an older version can still write over a change made in between, so please update every device.
- **Properties and templates.** One value that does not fit its field no longer hides all of a note's properties, and the sheet says when a block cannot be read at all. Because more notes are now read, databases, filters and the tag tree can show notes they missed before; in an encrypted workspace a slice rule by tag or property also matches such a note, and it becomes visible to the slice's members with the next sync. A note made from a template no longer keeps `plainva.tasks: false` or the database assignment, `{{daily}}` works in the daily note, and a note made with the capture button, from a link or from the share sheet gets the vault's type.
- **Files stay intact.** A file in another encoding shows **This file is not text** and is never written over as text. On the iPhone a file in the app's own storage keeps its byte order mark. A file from a classic Mac is read line by line, and its first change turns the line endings and says so.
- **Index.** A file that cannot be read no longer takes the whole index down; it is left out and named ([#125](https://github.com/plainva/plainva/issues/125)). On the iPhone a picked folder is listed by the desktop's rules, and **Rebuild index** reads every file again.
- **Mail.** The phone reads mail as it is really built: a `=` inside base64 no longer costs the whole message and its attachments, and a part without header lines keeps its first paragraph. In **All inboxes** a row acts in its own mailbox, a list that arrives late no longer lands under another folder, and pull to refresh works in the mail list.
- **A vault switch is offered, not taken.** When a calendar or file connection comes back while unsaved input is on screen, the app offers to switch to the connection's vault instead of leaving the input behind.
- Tasks due from ordinary notes (`- [ ] … 📅 YYYY-MM-DD`) now appear under **Due** on the phone's **Today** screen, among the tasks of both shells' calendars and in the home-screen widget, not only those from a task database.

Encrypted workspaces, the on-device calendar, voice notes and the location stamp remain experimental.

The APK is attached to this release. The AAB is the signed Google Play delivery artifact. This mobile GitHub release is marked as a pre-release so that it does not replace the desktop updater release.
