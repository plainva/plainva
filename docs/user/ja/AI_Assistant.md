# AIアシスタント（ベータ版）

最終更新: 2026-09-24

Plainvaは、選んだAIモデルでノートについての質問に答えられます。保管庫を読み、使用したノートを示し、ノートやビューを開くこともできます——何も変更はしません。アシスタントは**実験的**で、オンにするまでは、端末ごとにオフのままです。

## オンにする

**設定 → AI・自動化**（アプリ側）を開き、**この端末でAIを使う**をオンにします。このスイッチがオフの間は、AIボタンもAIタブもコンパニオンもありません。質問するまで、どこにも何も送信されません。

## プロバイダーを選ぶ

Plainvaは独自のAIサービスを持ちません: 自分で選んだプロバイダーを、自分のキーで使います。すべてのプロバイダーを選べます。Plainvaが利用条件と保持期間を示すので、それをもとに決められます——除外されるものはありません。

| 種類 | プロバイダー |
|---|---|
| クラウドプロバイダー | Anthropic、OpenAI、Google Gemini |
| ゲートウェイと自前のサーバー | OpenRouter、任意の**OpenAI互換サーバー** |
| このコンピューター上（デスクトップ） | Ollama、LM Studio |

1. **AI・自動化**で**プロバイダーを追加**を開き、一覧から一つを選びます。各項目には利用条件の短い説明が付いています——たとえばGoogleの無料アクセスでは入力内容を人が読むことがある、というように。
2. **キーを入力**でキーを入力します。キーはこの端末の安全な保存領域に入り、Plainvaは二度と表示しません——AIにも画面にも。
3. **接続をテスト**はプロバイダー自身のモデル一覧を読み込みます。失敗した場合、メッセージがその理由を示します（キーが拒否された、接続できない、未知のモデルなど）。

**OpenAI互換サーバー**はアドレスで追加します。追加する前にPlainvaはオペレーティングシステムのウィンドウでもう一度確認を求め、確認したアドレスにのみ送信します。暗号化されていない`http`はこの端末上のサーバーにのみ使えます。それ以外はすべて`https`が必要です。

まだキーがない場合: このコンピューター上のモデル（Ollama、LM Studio）は無料で、各プロバイダーのコンソールでキーを発行できます。

## モデルとプロファイル

4つのプロファイル——**高速**、**バランス**、**強力**、**ローカル**——はモデルの割り当てです。プロバイダーのリストから、またはプロバイダーが呼ぶとおりのモデルIDを入力して、それぞれにプロバイダーとモデルを選んでください。**新しい会話の既定**が、新しい会話がどのプロファイルで始まるかを決めます。Plainvaはどのモデルも「最良」とは呼びません。

## 質問する

- **デスクトップでは:** アクションバーのAIボタン、**Ctrl+J**（macOSでは⌘J）、またはコマンドパレットの**AIに質問**が、コンパニオン——作業の上に重なる小さなウィンドウ——を開きます。**タブとして開く**は同じ会話をAIタブへ移し、そこに会話が一覧表示されます。
- **スマートフォンでは:** ノートの⋮メニューの**AIに質問**が、そのノートの上にAIシートを開きます。**AI**エリア（**エリア**内、配置していればナビゲーションバー内）は会話をフル画面で表示し、**会話**は以前のものを一覧表示します。

開いているノートは自動的に含まれます。外したい場合は、その✕でコンテキストから外してください。**ノートをピン留め…**でさらにノートを追加できます。アシスタントは自分でも調べものができます: 保管庫を検索し、ノートとその節を読み、タスクを一覧表示し、ノートやビューを開きます。変更、作成、削除は一切できません。

すべての会話は「回答はAIが書いています — ⟨モデル⟩（⟨プロバイダー⟩経由）」という行で始まります。各回答の下には、何がどこへ送られたかを示す行があります: ノートの件数、おおよそのトークン数、そして——プロバイダーが価格を公開している場合は——概算の費用です。**停止**はいつでも回答を終了させます。

回答内のリンクは、アドレスを確認したあとでのみ開きます。回答内の画像は読み込まれることがありません。

## プライバシールール

一部のノートはクラウドプロバイダーに決して届くべきではありません。ルールはノートのFrontmatterに置けます:

```yaml
plainva:
  ai:
    cloud: deny
```

または、フォルダー全体には**設定 → AI・自動化**（保管庫側）に置き、そこがルールを`.agent/policy.yml`に書き込みます。クラウドから遠ざけられたノートは本文もタイトルも一切渡さず——ほかのノートからそこへのリンクも伏せられます。この端末上のモデルは常に許可されます。暗号化ワークスペースは、そこで許可しない限りクラウドをオフのままにします。正確な形式は[ファイル形式リファレンス](File_Format_Reference.md)にあります。

## 履歴と利用状況

会話はこの端末に、保管庫ごとに残ります——保管庫の中には入らず、同期もされません。**会話を保持**が期間を決め、一覧から個別の会話を削除することも、保管庫のすべてを一度に削除することもできます。**今月の利用状況**は、プロバイダーとモデルごとのトークンを合計します。

## ベータ版の制限

- デスクトップでは、AIはメインウィンドウでのみ動作します。
- スマートフォンでは、アプリを開いている間だけ回答が届きます。
- アシスタントは読むだけです。変更を提案として示す機能は、後のバージョンで追加されます。
