# スキル（ベータ版）

最終更新: 2026-10-06

スキルとは、繰り返し行う作業のための指示のまとまりです。会議の準備、タスクの整理、週の振り返りなどがあります。Plainvaには12個が付属しており、自分で書くこともできます。スキルはオープンな形式 Agent Skills（`SKILL.md` を含むフォルダー）を使うため、この形式を読めるほかのAIアプリでも使えます。

## スキルを使う

スキルはワンクリックで始められます。空の会話のチップ（よく使う3つ）、AIタブの**スキル**、スマートフォンでは**会話 → スキル**、またはコマンドパレットから選びます。会話はそのスキルとともに進み、指示が一緒に送られ、スキルが挙げるツールとフォルダーだけを使います。

ただ質問するだけでもかまいません。どの会話でもAIは有効なスキルの名前と説明を知っており、質問に合うときにスキルを読み込みます。「次の会議の準備をして」と言うだけで十分です。

## Plainvaに付属のスキル

| スキル | できること |
|---|---|
| **今日のオリエンテーション** | 今日大切なこと：期限のタスク、予定、最近取り組んだこと。 |
| **週の振り返り** | 過去7日間と来週、そして3つの提案。 |
| **プロジェクトの状況** | プロジェクトの目標、進捗、未解決の点、次の一歩。 |
| **会議の準備** | 以前のノートと未決事項から会議を準備し、終わった会議はまとめます。 |
| **タスクの整理** | 未完了のタスクを整理：今やること、後回しにできること、やめること。 |
| **リサーチ** | 質問をウェブとノートで調べ、すべての出典を明示します。 |
| **メールとカレンダー** | 最近のメールと今後の予定を確認します：返信が必要なもの、準備すること、そこから生じるタスク。 |
| **書く・推敲する** | ノートを要約・短縮・書き直し、取り込めるテキストにします。 |
| **ナレッジの手入れ** | 同じ内容のノート、古くなったノート、何ともつながっていないノートを見つけます。 |
| **リンクの整理** | ノートのリンクを確認：どこにもつながらないもの、足りないもの、一方向のもの。 |
| **プライバシーの確認** | ノートの中でこのデバイスに残すべきものを見つけ、ルールを提案します。 |
| **振り返り** | 1日や1週間のノートを一緒に振り返ります。やさしく、診断はしません。 |

どれも読むだけです。ノートを変更したり、何かを送信したりはしません。インターネットを使うのは**リサーチ**だけ、メールを読むのは**メールとカレンダー**だけです——下をご覧ください。プライバシーの確認と振り返りはこのデバイス上のモデル向けで、クラウドのモデルを使うと送信の概要にそう表示されます。どのスキルも**スキル**でオフにでき、その設定はこのデバイスのこの保管庫に有効です。**自分の版を作る**で付属のスキルを保管庫にコピーし、そこで変更できます。

## インターネットとメール

**リサーチ**は、Plainvaに付属するスキルのうち、インターネットを使う唯一のスキルです。始めるかどうかは、入力欄の下の地球のアイコンと同じく、その会話についてのあなたの選択です。**この保管庫でAIにインターネットの使用を許可する**をオンにしている場合は、検索してページを読みます。ノートが会話に含まれている間は、[AIアシスタント](AI_Assistant.md)の**インターネットを使う**で説明しているとおり、ページや検索のたびに先に確認します。オフの場合は、ノートの中だけで調べ、そのことを伝えます。インターネットなしで始めた会話でAIがこのスキルを自分で読み込んだ場合も、同じです。

**メールとカレンダー**は、どの会話とも同じ質問でメールを読みます。初回は**メールを読み取りますか？**と尋ねます。メッセージの本文を自分で読むことはなく、ツールを持たない2番目の読み手が報告を書きます。どちらも[AIアシスタント](AI_Assistant.md)で説明しています。

自分のスキルがインターネットを使うのは、`allowed-tools`の行が`web_search`または`fetch_url`を挙げている場合だけです。承認の前に、**確認して承認**に**この保管庫で許可した場合に、インターネットを使います。**と表示されます。ツールを挙げていないスキルがインターネットを持ち込むことはありません。

テスト実行がインターネットを使うことはなく、確認を求めることもありません。このセッションで読み取りを許可されていないメールは、未読のままです。

## 自分のスキル

**新しいスキル**では、名前、説明（AIはこれを見てスキルを選びます）、指示を入力します。Plainvaはそれを `.agent/skills/<名前>/SKILL.md` として保管庫に書き込み、ほかのノートと同じように保管庫と一緒に移動します。**編集**でファイルをノートのように開けます。

**インポート…**では、スキルを `.zip` または `.skill` ファイルとして取り込めます。何かを書き込む前に、Plainvaは確認します。形式に沿ったスキルが1つだけあること、フォルダーの外に出るパスがないこと、サイズの上限です。ライセンス、実行しないスクリプト、Plainvaにないツールも示します。隠しファイル（名前がドットで始まるもの）はスキルの一部ではなく、取り込まれません。

## 承認するまで何も実行されません

保管庫のスキルが新しく届いたか変更された場合（同期、インポート、このデバイスやほかのデバイスでの編集）、**このデバイスで**承認するまで実行されません。そうしたスキルは**スキル**の上部の**承認待ち**と、**設定 → AI・自動化**（保管庫側）に表示されます。**確認して承認**では、スキルにできること、前回の承認からの変更点、指示、ファイル、置き場所を確認できます。承認はまさにこの版にだけ有効で、どんな変更でも取り消されます。承認はこのデバイスに保存され、保管庫には保存されません。

保管庫の最上位にある `AGENTS.md` も同じです。承認すると、その常設の指示がすべての新しい会話に加わります。スキルも `AGENTS.md` もプライバシーのルールを解除することはできず、スキルが会話以上の権限を得ることはありません。狭めることしかできません。

## モデルでスキルをテストする

スキルにはテストシナリオを付けられます。スキルを開始するメッセージと、良い実行が行うことです。付属のスキルにはあらかじめ用意されています。自分のスキルでは、スキルのフォルダー内の `tests/scenarios.json` に書きます。

```json
{
  "version": 1,
  "scenarios": [
    {
      "id": "rates",
      "message": "Check the offer against last year's rates.",
      "tools": { "required": ["read_note"], "forbidden": ["run_command"] },
      "cites": ["Offer"],
      "never": ["internal margin"]
    }
  ]
}
```

`tools` は良い実行が使うツールと使ってはいけないツール、`cites` は回答が挙げるノート、`never` は回答に現れてはいけないテキストを示します。1 つのスキルのシナリオは最大 8 件です。

**スキル** の一番下、またはスキルのメニューにある **⟨モデル⟩ でテスト** で、新しい会話が使うモデルに対してシナリオを実行します。自動では何も始まりません。ダイアログがまず、何件のシナリオをどのモデルで実行するかを示し、あなたが米ドルで **上限** を決めます。上限に達すると、次のシナリオの前でテストは終了します。モデルの価格が不明な場合は、決まったトークン数で終了します。このデバイス上のモデルには上限は不要です。

各シナリオは、そのスキルの通常の実行です。手動で実行したときと同じように保管庫を読み、送信前の同じ概要を通り、使用量に加算され、会話が履歴に残ります（次の実行で置き換えられます）。終わると、各シナリオの結果が言葉で示され、スキルの行に前回の実行結果が表示されます。結果は、1 つのモデルとスキルの 1 つの版についてのものです。別のモデルを選んだり、スキルを変更したりすると、行はもう意味を持たない結果ではなく、そのことを示します。付属のシナリオの一部は、Plainva のテスト用保管庫のノートについて尋ねるものです。あなたの保管庫では対象外となり、ダイアログは不合格とせず別に数えます。

## プロバイダーに送られるもの

送信の概要の**指示**には、一緒に送られるものが表示されます。会話のスキル、AIが読み込めるスキルの一覧、`AGENTS.md` です。保管庫の指示が初めてクラウドに送られるときは、概要がもう一度表示されます。スキルの中の見えない文字がモデルに届くことはありません。

## ベータ版の制限

スキルはスクリプトを実行しません。自分のスキルは、MCPサーバー経由で接続したAIアプリには提供されず、Plainvaに付属のスキルだけが提供されます。
