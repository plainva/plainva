# 外部エージェント（ベータ版）

最終更新: 2026-10-07

外部エージェントは、ほかのメーカーのAIプログラムです——自分でコンピューターにインストールし、自分の契約やキーで自らサインインしたエージェントです。Plainvaは、そうしたエージェントを保管庫のフォルダーで起動し、そのセッションをAIタブに表示できます。実験的なAI機能の一部で、デスクトップでのみ動作します。

外部エージェントはPlainvaのアシスタントではありません。[AIアシスタント](AI_Assistant.md)は、概要で示したものだけを送り、プライバシールールが止めているものは決して送りません。エージェントは自分で読み、自分で送信します。このページでは、そうしたセッションでPlainvaが管理するもの——そして管理しないもの——を説明します。

## Plainvaが管理しないもの

- **プログラム。** エージェントは他者のプログラムです。このコンピューター上で、あなたの権限で、保管庫のフォルダーで動き、囲いはありません。あなたが読めるもの、変更できるものは、すべて読み、変更できます。
- **読むものと送るもの。** ファイルを自分で読み——クラウドに送らないようにしているノートも含みます——、選んだものを自分のサービスに送ります。プライバシールールも送信前の概要も届かず、送信の前に何かが尋ねることもありません。
- **自分で書き込むもの。** エージェントが自分で行った変更は、提案を経ずに、すぐ保管庫に入ります。エージェントがそうした変更を報告すれば、セッションがそれを伝えます。報告しない変更は、Plainvaには見えません。
- **サインイン。** エージェントは自分でサインインします。Plainvaがその認証情報を見ることはなく、保存もしません。

エージェントは、内容がそのエージェントのサービスに届いてもよい保管庫でだけ起動してください。

## Plainvaが管理するもの

- **Plainva自身のツール。** **このコンピューターのAIアプリにこの保管庫の読み取りを許可**がオンの場合、Plainvaのツールがエージェントに提供されます——[AIアプリの接続](Connect_AI_Apps.md)のどのアプリとも同じものです: 許可したフォルダーだけ、クラウドやインターネットに出さないノートは決して含まず、変更の提案を許可しない限り読み取り専用です。
- **エージェントがPlainvaに読み取りを求めるもの。** クラウドに送らないノートとPlainva自身のフォルダーは渡しません。エージェントにそう伝えられ、あなたにも伝えられます。
- **エージェントがPlainvaに書き込みを求めるもの。** 何も書き込まれません。ノートへの変更はエージェントの名前による提案のまとまりになり、新しいノートは作成するまで待機します。
- **ターミナルなし。** Plainvaは、エージェントに専用のターミナルを提供しません。

## エージェントを追加する

1. メーカーの説明に従って自分でエージェントをインストールし、そのプログラムでサインインします。
2. **設定 → AI・自動化**（アプリ側）を開きます。**外部エージェント**では、Plainvaが名前で知っていてインストール済みと分かったエージェントに**このコンピューターで見つかりました**と表示され、**追加**で追加できます。Agent Client Protocolに対応したそのほかのプログラムは、**別のエージェント**の**エージェントを追加…**を選び、**名前**、**プログラム**、**引数（1行に1つ）**を入力します。
3. 記憶される前に、システムがコマンド全体をもう一度表示します。

Plainvaはエージェントをインストールせず、ダウンロードもしません。確認したそのプログラムを、シェルを介さず直接起動します。コマンドはこの端末に記憶され、保管庫には決して保存されません。**削除**すると、Plainvaはエージェントの起動方法を忘れます。プログラム自体とそのサインインはそのまま残ります。

## セッションを開始する

AIタブを開き、**エージェント**を選びます。何かが起動する前に、**⟨エージェント⟩ を起動する前に**が、エージェントが自分で行うこととPlainvaが管理することを列挙し、Plainvaのツールが提供されるかどうかを示します。**セッションを開始**で、エージェントのプログラムが保管庫のフォルダーで起動します。Plainvaを開いてから、ある保管庫で初めてエージェントを起動するときは、システムがフォルダーとコマンド全体を示して、もう一度確認します。

同時に動くセッションは一つで、開始した保管庫に属します。**セッションを終了**でエージェントのプログラムが止まり、保管庫またはPlainvaを閉じても止まります。動いている間、セッションの最初の行が、エージェントが誰であるか、そしてプライバシールールが適用されないことを示します。暗号化ワークスペースの中では、エージェントは起動されません。

## サインインする

サインインしていないエージェントはそう伝え、セッションに**⟨エージェント⟩ がサインインを求めています**と、エージェントが挙げた方法が表示されます。エージェントによって、方法を選ぶとエージェント自身のプログラムのターミナルウィンドウが開くか、エージェントが自らサインインへ案内します。Plainvaは待機し、その後エージェントを起動し直します。ターミナルを開けない場合、Plainvaは自分のターミナルで実行するコマンドを表示します。その後**もう一度試す**を選びます。Plainvaにサインインの内容は一切見えません。

## セッションの中で

エージェントにしてほしいことを入力します。開いているノートはエージェントに示されます——名前と場所であり、本文ではありません——。入力欄の上で外すこともできます。クラウドに送らないノートが示されることはありません。セッションには、エージェントの発言、その計画、各ステップが、エージェントが挙げた保管庫のファイルとともに表示されます。

エージェントがあるステップについて許可を求めると、**⟨エージェント⟩ からの確認**に表示されます。文言はエージェント自身のもので、選択肢もエージェントが提示したものです——**許可**、**常に許可**、**拒否**、**常に拒否**。回答はエージェントにだけ届きます。許可のあとに何をするかはエージェント自身の行いであり、「常に」はPlainvaではなくエージェントが守る約束です。

**停止**は、エージェントが作業中の回答を終わらせます。

## エージェントが書き込むもの

**Plainva経由。** エージェントがPlainvaに渡した変更が、ノートに書き込まれることはありません。エージェントの回答が終わると、変更された各ノートに、**⟨名前⟩（外部エージェント）**の署名が付いた提案のまとまりが一つ付きます。**提案**で、人による提案と同じく、変更を一つずつ、またはまとめて適用または却下します。まだ存在しないノートは**エージェントからの新しいノート**に表示されます。**作成**で書き込まれ——`generated`の印が付き、作成者はエージェントです——、**破棄**で取り下げられます。エージェントが持ち込んだウェブアドレスは、何も開いたり読み込んだりしない形で書かれます（`https[://]…`）。

Plainvaはすべてを受け取るわけではありません: Markdownノートだけ、その本文だけでプロパティは対象外、AIルールや信頼フィールドを含むノートは不可、クラウドに送らないものは不可、一つのノートへの変更は一度に150件までです。受け取らなかったものはセッションが伝え、エージェントにも伝えられます。

**自分で。** エージェントは、ほかのプログラムと同じく、自分でファイルを書き込むこともできます。エージェントがそうした変更を報告すると、セッションに**エージェントが ⟨ノート⟩ を自分で変更しました。提案を経ずに保管庫に入っています。**と表示されます。エージェントがどちらの道を取るかは、Plainvaには約束できません。エージェントとその設定次第です。設定では、各エージェントに、このコンピューターでの最新の記録が表示されます——Plainva経由の変更がいくつで、自分で書き込んだものがいくつか。

## Plainvaが保持するもの

- **この端末に:** 確認したコマンド、エージェントに付けた名前、変更についての最新の記録——Plainva自身のデータの中で、保管庫には決して入りません。
- **保管庫ごとに:** **この保管庫での最近のセッション**に、セッションがいつ、どのエージェントで行われ、メッセージ、Plainva経由の変更、自分での変更がいくつあったかが並びます——発言の内容は決して残りません。
- **セッションそのものは残しません:** あなたとエージェントの発言は、セッションを閉じると消えます。エージェントが自分の側で何を保持するかは、エージェントの問題です。

エージェントのプログラムが自ら終了した場合、セッションがそう伝え、**最後の出力を表示**でプログラムが書き出した最後の部分を表示できます。

## 制限

- デスクトップのみ、メインウィンドウのみです。スマートフォンではPlainva自身のアシスタントを使います。
- 暗号化ワークスペースでは使えません。
- セッションは同時に一つで、履歴はありません。終了したセッションを開き直すことはできません。
- エージェント独自のモード、モデル、コマンドはPlainvaからは選べず、画像を送ることもできません。
- これまでのところ、Plainva自身のテスト用エージェントでのみ試しています。どのエージェントがここで動作し、どれが変更をPlainvaに渡すかは、試してみて分かります——フィードバックを歓迎します。
