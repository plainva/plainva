# ジャーナル

最終更新: 2026-09-22

ジャーナルは、ノートを開かずに何かを書き留めるすばやい方法です: 思いついたこと、電話の内容、その日についての一行。すべてのエントリは時刻付きのふつうのリスト行です——`- 14:05 ルーターは地下にある`——**今日のデイリーノート**の見出しの下にあります。新しいファイル形式もデータベースもありません: エントリはデイリーノートの中で暮らしており、どのエディターでも読め、Obsidianのジャーナル系プラグイン（Thino、Knomo）とも相性が良好です。

## エントリを書く

入力欄は一つ、押すのは**Enter**一回。Plainvaが時刻を記録し、あなたはテキストを入力するだけです。タグ、リンク、二行目もそのまま入力できます——テキストはふつうのMarkdownです。

- **デスクトップでは:** `Ctrl+Shift+J`でPlainva内のどこからでも**ジャーナルエントリ**の入力欄が開きます。同じ入力欄はサイドバーの**＋**メニュー、コマンドパレット、トレイメニュー（**ジャーナルエントリ**）にもあります。`Enter`で保存、`Shift+Enter`で改行、`Esc`で破棄します。
- **スマートフォンでは:** **＋**ボタンが**ジャーナルエントリ**を提供し、ジャーナル画面には専用のペンボタンがあります。アプリアイコンの長押しでも**ジャーナルエントリ**が表示されます——Androidではランチャーのショートカットとして、iOSではクイックアクションとして。そこでは`Enter`は改行のままで、**エントリを保存**が保存します。
- **共有シートから（スマートフォン）:** Plainvaを選んで**ジャーナルに保存**にチェックを入れます——テキストとリンクがエントリになり、共有されたファイルは添付ファイルのフォルダーに入って埋め込まれます。
- **画像を使う場合:** スマートフォンの入力欄には**写真を追加**があります。デスクトップでは、クリップボードから画像を入力欄に貼り付けます。画像は添付ファイルの保存先に置かれ、エントリに埋め込まれます。

今日のデイリーノートがまだない場合は、その途中で作成されます——デイリーノートのテンプレートから、その質問には答えずに。保存後、通知が**エントリを保存しました**と表示し、**元に戻す**を提供します。

入力欄の役目はひとつ、ジャーナルエントリです。その下の**代わりにタスクを作成**は、入力した内容を[タスクビュー](Tasks.md)へ引き渡していつものようにタスクを作り、入力欄を閉じます。チップの**タスクとして**は別物です。エントリはジャーナルに残したままチェックボックスを付け（`- [ ] 14:05 交換部品を注文`）、タスクビューの**ノートから**にも並びます。チップのボックスは、選ぶまで空のままです。

## ジャーナルビュー

**ジャーナルを開く**（デスクトップではアクションバー、スマートフォンでは**エリア**、またはコマンドパレット）は、すべての日を一つの流れとして表示します: 最新の日が一番上、一日の中では最新のエントリが先頭です。リンクは開き、タグはピルになり、埋め込まれた画像はプレビューとして表示され、長いエントリは折りたたまれます——**もっと見る**で開きます。

- **検索と絞り込み:** 検索フィールドは読み込み済みの日を検索します。チップの**すべて**、**タスクのみ**、そして最も頻度の高いタグが流れを絞り込みます。エントリ内のタグをクリックすると、そのタグで絞り込まれます。
- **過去の日:** Plainvaはエントリのある直近14日分を読み込みます。**過去を読み込む**は次の範囲を取得し、**日へ移動**は日付ピッカーを開きます。そこではエントリのある日にマークが付き、選んだ日まで遡って読み込まれます。
- **ノートを開く**は日の見出しにあり、そのデイリーノートを開きます。エントリをクリックすると、その行でノートが開きます。
- タスクのエントリの**チェックボックス**は、流れの中で直接チェックできます。完了日や繰り返しタスクの次回分を含め、タスクビューと同じように振る舞います。

各エントリにはメニューがあります（デスクトップでは右クリックまたは**⋯**、スマートフォンでは**⋯**、長押し、またはスワイプ）: **編集**はその場でテキストを変え時刻はそのまま保ち、**コピー**はテキストをコピーし、**タスクにする**はチェックボックスを追加し、**エントリに戻す**はそれを取り除き、**ノートで表示**はその行へジャンプし、**削除**はエントリを取り除きます——続く通知の**元に戻す**とともに。

ある一日のエントリは、その日を見ている場所にも表示されます。デスクトップでは右サイドバーの**ジャーナル**セクション（開いているデイリーノートの日付、なければ今日）、スマートフォンでは**今日**画面の選択中の日付です。サイドバーでは他と同じセクションで、折りたためて状態を覚え、非表示にもでき、最初は閉じています。各行は一行で、そこでは何も操作しません。すべての行が同じ左端から始まり、タスクはチェックボックスではなく右端の控えめな印で示されます（チェックはストリームかノートで）。見出しの鉛筆はその日付を宛先にした通常の**ジャーナルエントリ**欄を開き、**すべての日**はストリームへ進みます。

## エントリの保存の仕組み

```markdown
## Journal

- 09:12 修理工場に電話した #顧客
- [ ] 10:30 部品を注文する
- 14:05 ルーターは地下にある
  鍵はベルガーさんが持っています。
```

- エントリはセクションの末尾に追加されるため、ファイルは時系列順に読めます。ビューでは最新のものが一番上に表示されます。
- 見出しは既定で**Journal**であり、保管庫ごとに**設定 → 保管庫 → コンテンツと構造**（**ジャーナルの見出し**；スマートフォンでは**設定 → コンテンツと構造**）で変更できます。見出しのレベルは関係ありません。見出しがない場合、Plainvaはノートの末尾に`## Journal`を追加します。設定を変更しても、既存の見出しの名前が変わることはありません。
- **一日の終わり**（設定の同じ場所）は一日の区切りを後ろにずらします。**04:00** にすると、真夜中から四時までに書いた内容はまだ前日のものとして扱われ、昨日のデイリーノートに入り、実際の時刻（`- 01:30 …`）を保ちます。ジャーナルの日付見出しには **04:00 まで** と表示されます。この区切りはデイリーノートとジャーナルにのみ適用され、カレンダーやタスクの期限には**適用されません**。水曜日の午前1時30分の予定は水曜日のままです。既定は**午前0時**で、この設定は Vault に属し、すべてのデバイスで有効です。
- Plainvaは`- 14:05:30 テキスト`（秒付き）やチェックボックス付きのエントリも読み取り、ノートがすでに書いている形でリストを続けます（`-`、`*`または`+`、エントリの間に空行があってもなくても）。既存の行が再フォーマットされることはありません。
- 安全に配置できない変更——例えば、セクション内のコードブロックが閉じられていない場合——はメッセージとともに拒否され、入力欄はあなたのテキストを保持します。

正確な形式は[ファイル形式リファレンス](File_Format_Reference.md)にあります。

## 二つの端末を同時に使うとき

二つの端末が、同期する前に同じデイリーノートへエントリを追加した場合、それは**競合ではありません**: Plainvaはエントリを時刻順に統合し、両方の端末のすべての行が保持されます。これは、両方の端末がその日のノートを別々に作成していた場合にも当てはまります。ノートに対するそれ以外の同時変更は、これまでどおり慎重に扱われます（[同期の互換性](Sync_Compatibility.md)を参照）。

## グローバルクイックキャプチャ（デスクトップ、任意）

**設定 → 起動と動作 → グローバルクイックキャプチャ**で**システム全体のショートカットでどこからでも記録する**をオンにできます。ショートカット——既定は`Ctrl+Alt+J`（macOSでは`Cmd+Option+J`）——は、ほかのアプリが前面にあっても、エントリの入力欄だけの小さなウィンドウを開きます。Plainvaが動いているあいだ（通知領域にあるときも）使えます。`Enter`はPlainvaで開いている保管庫の今日のデイリーノートにエントリを書き込んでウィンドウを閉じ、`Esc`は破棄します。

- **変更**は新しいショートカットを記録します: 望みの組み合わせを、`Ctrl`、`Alt`、または Windows/Command キーと合わせて押してください。**既定に戻す**で既定に戻ります。
- ほかのアプリがすでにそのショートカットを使っている場合、またはシステムが受け付けない場合、Plainvaは何もしないショートカットを残す代わりに、スイッチの下でその旨を伝えます。
- **Wayland**（Linux）では、システムがアプリにシステム全体のショートカットを与えません。Plainvaはその旨を伝え、何も登録しません。通知領域の「ジャーナルエントリ」と`Ctrl+Shift+J`が同じ入力欄を開きます。
- このショートカットは端末に属し、設定プロファイルの一部ではありません。
