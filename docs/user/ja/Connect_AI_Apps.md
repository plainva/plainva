# AIアプリの接続（ベータ）

最終更新: 2026-10-07

コンピューター上のAIアプリ——Claude Code、Claude Desktop、Cursor、VS Code、そのほかModel Context Protocol（MCP）に対応したもの——は、Plainvaを通じて保管庫を読むことができます: 検索し、ノートとその節、アウトライン、バックリンク、データベース、タスク、最近のノートを読み、Plainvaでノートを開きます。アプリが自分で何かを変更することはありません。あなたが許可したアプリは変更を提案でき、その提案はあなたが判断するまで待機します（下記参照）。実験的なAI機能の一部で、デスクトップでのみ動作します。

逆の向き——自分で接続したサーバーのツールをPlainvaのアシスタントが使うこと——は、[AIアシスタント](AI_Assistant.md)の**外部ツール（MCP）**で説明しています。

三つ目の方法——Plainvaがほかのメーカーのエージェントを保管庫のフォルダーで起動し、そのセッションをAIタブに表示すること——は、[外部エージェント](External_Agents.md)で説明しています。

## 仕組み

Plainvaはアプリの隣に小さな補助プログラム`plainva-mcp`を同梱しています。AIアプリがそれを起動し、補助プログラムはこのコンピューターのプライベートなチャネル——Windowsでは名前付きパイプ、macOSとLinuxではプライベートなフォルダー内のソケット——で起動中のPlainvaに接続します。ネットワークポートは一切開きません。Plainvaが保管庫を開いた状態で起動している必要があり、そうでなければアプリに分かりやすいメッセージが届きます。

## オンにする

1. **設定 → AI・自動化**を開き、**この端末でAIを使う**をオンにします。
2. **このコンピューターのAIアプリにこの保管庫の読み取りを許可**をオンにします。
3. アプリを設定します（下記参照）。最初の接続時、Plainvaはどのアプリか、どのプログラムが起動したか、どのフォルダーを読んでよいかを尋ねます。何も選択されていないので、フォルダーまたは**保管庫全体**を選び、**許可**を押します。**拒否**するとアプリは断られ、Plainvaは10分間そのアプリについて再び尋ねません。フォルダーの下には**変更を提案できる**があります。チェックを入れない限りオフです。許可される内容は後述します。

アプリは次回のためにシステムのキーチェーンに秘密を保存します。フォルダーはアプリごと、保管庫ごとに許可されます: 別の保管庫では、アプリは改めて尋ねます。

## アプリを設定する

- **Claude Code:** 設定から**Claude Code用のコマンド**をコピーし、ターミナルで実行します。
- **Claude Desktop:** **パッケージを作成…**で`plainva.mcpb`ファイルが書き出されます。開くとClaude DesktopにPlainvaがインストールされます。
- **ほかのアプリ（JSON）:** 設定をコピーし、アプリのMCP設定（たとえばCursorの`mcp.json`）に追加します。

## アプリに見えるもの

許可したフォルダーだけ、そしてプライバシールールが、インターネットに接続できるクラウドのモデルに送ることを認めたものだけです（アプリは読んだものをどう扱うかPlainvaから見えないため、そのようなモデルとして扱われます）: `cloud: deny`または`web: deny`のノート、またはそのいずれかのルールのあるフォルダー内のノートはアプリにとって存在しません——本文もタイトルも見えません——。それらへのリンクは伏せられ、ジャーナルの場所は決して送られません。Plainva自身のフォルダー（`.plainva`、`.agent`）とルールそのものは決して読めません。リクエストと回答のすべてのパスは2回確認されます: アプリのウィンドウと、Plainvaのネイティブ部分で。

設定には、許可したアプリとそのフォルダー、最近のリクエストが表示されます。**削除**でアプリの許可をすべての保管庫で取り消します。これはすぐに有効になり、その時点で接続中のアプリにも適用されます。

ツールのほかに、Plainvaは3つのスキルをアプリの言語でプロンプトとして提供します：`daily-orientation`、`weekly-review`、そしてプロジェクト名を尋ねる`project-status`です。プロンプトに対応したアプリでは、コマンドの一覧に表示されます。

## アプリに変更を提案させる

読み取りの許可は、書き込みの許可ではありません。アプリが変更も提案できるかどうかは、別の回答です。最初の接続時の確認にある**変更を提案できる**、または後から設定のスイッチ**…は変更を提案できる**で決めます。アプリごと、保管庫ごとの設定で、あなたがオンにするまではオフです。アプリの次のリクエストから有効になり、追加のツールはアプリが再接続すると表示されます。

許可したアプリには6つのツールが追加されますが、いずれも保管庫を変更しません。

- **ノートへの変更**（本文またはプロパティ）は、ノートの余白に提案として置かれ、アプリの名前と「（AIアプリ）」の署名が付きます。ほかの提案と同じく、そこで変更を1つずつ適用または却下します（[コメントと提案](Comments_and_Suggestions.md)を参照）。
- **新しいノート**は、AIタブの**保留中**に下書きとして置かれます。そこで**作成**を選ぶと、ノートが作成されます。
- **名前の変更・移動・削除**は、まず確認を求めます。Plainvaが自身のウィンドウで何が起きるかを表示し（名前の変更では、リンクが追従するノートも表示します）、アプリにはPlainvaが待機中であることが表示されます。Plainvaで**許可**を選び、アプリが続行して初めて、Plainvaはあなたが手動で行うときと同じ方法で実行します。アプリに伝わるのは、実行されたかどうかだけです。削除の場合は、そのあとPlainvaが自身の削除ダイアログを開き、そこで確認するまで何も消えません。このような表示ができないアプリには、この3つのツールは提供されません。

アプリが持ち込んだウェブアドレスは、アシスタントの場合と同じく、何も開いたり読み込んだりしない形（`https[://]…`）で書かれます。ノート自身のプライバシールール（`plainva.ai`）をアプリが設定することはできず、暗号化されたワークスペースでは提案・下書き・計画は行われません。設定の**最近のリクエスト**には、各リクエストがどうなったかが表示されます。Plainvaがあなたに確認したことや、あなたが拒否したこともわかります。

## 制限

- デスクトップのみ: スマートフォンではこうしたアプリは動かず、iOSもAndroidもアプリが別のアプリにプライベートなチャネルを提供することを認めていません。
- ブラウザーのChatGPTやclaude.aiからは届きません: それらはインターネット上のサーバーにしか接続できず、Plainvaはそうしたサーバーを運用していません。
- アプリが自分で保管庫を変更することはありません。アプリが書いたものは提案または下書きとして待機し、名前の変更・移動・削除にはPlainvaでのあなたの許可が必要です。
