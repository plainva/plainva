# AIアプリの接続（ベータ）

最終更新: 2026-09-29

コンピューター上のAIアプリ——Claude Code、Claude Desktop、Cursor、VS Code、そのほかModel Context Protocol（MCP）に対応したもの——は、Plainvaを通じて保管庫を読むことができます: 検索し、ノートとその節、アウトライン、バックリンク、データベース、タスク、最近のノートを読み、Plainvaでノートを開きます。何も変更できません。実験的なAI機能の一部で、デスクトップでのみ動作します。

## 仕組み

Plainvaはアプリの隣に小さな補助プログラム`plainva-mcp`を同梱しています。AIアプリがそれを起動し、補助プログラムはこのコンピューターのプライベートなチャネル——Windowsでは名前付きパイプ、macOSとLinuxではプライベートなフォルダー内のソケット——で起動中のPlainvaに接続します。ネットワークポートは一切開きません。Plainvaが保管庫を開いた状態で起動している必要があり、そうでなければアプリに分かりやすいメッセージが届きます。

## オンにする

1. **設定 → AI・自動化**を開き、**この端末でAIを使う**をオンにします。
2. **このコンピューターのAIアプリにこの保管庫の読み取りを許可**をオンにします。
3. アプリを設定します（下記参照）。最初の接続時、Plainvaはどのアプリか、どのプログラムが起動したか、どのフォルダーを読んでよいかを尋ねます。何も選択されていないので、フォルダーまたは**保管庫全体**を選び、**許可**を押します。**拒否**するとアプリは断られ、Plainvaは10分間そのアプリについて再び尋ねません。

アプリは次回のためにシステムのキーチェーンに秘密を保存します。フォルダーはアプリごと、保管庫ごとに許可されます: 別の保管庫では、アプリは改めて尋ねます。

## アプリを設定する

- **Claude Code:** 設定から**Claude Code用のコマンド**をコピーし、ターミナルで実行します。
- **Claude Desktop:** **パッケージを作成…**で`plainva.mcpb`ファイルが書き出されます。開くとClaude DesktopにPlainvaがインストールされます。
- **ほかのアプリ（JSON）:** 設定をコピーし、アプリのMCP設定（たとえばCursorの`mcp.json`）に追加します。

## アプリに見えるもの

許可したフォルダーだけ、そしてプライバシールールがクラウドのモデルに送ることを認めたものだけです: `cloud: deny`のノート、またはそのルールのあるフォルダー内のノートはアプリにとって存在しません——本文もタイトルも見えません——。それらへのリンクは伏せられ、ジャーナルの場所は決して送られません。Plainva自身のフォルダー（`.plainva`、`.agent`）とルールそのものは決して読めません。リクエストと回答のすべてのパスは2回確認されます: アプリのウィンドウと、Plainvaのネイティブ部分で。

設定には、許可したアプリとそのフォルダー、最近のリクエストが表示されます。**削除**でアプリの許可をすべての保管庫で取り消します。

## 制限

- デスクトップのみ: スマートフォンではこうしたアプリは動かず、iOSもAndroidもアプリが別のアプリにプライベートなチャネルを提供することを認めていません。
- ブラウザーのChatGPTやclaude.aiからは届きません: それらはインターネット上のサーバーにしか接続できず、Plainvaはそうしたサーバーを運用していません。
- 読み取りのみです。アプリに変更を提案させる機能は今後のバージョンで提供します。
