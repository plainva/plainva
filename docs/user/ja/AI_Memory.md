# 記憶（ベータ版）

最終更新: 2026-10-09

記憶には、あなたとあなたの仕事について、AIに繰り返し伝えなくても知っておいてほしいこと——何をしているか、回答の好み、取引先は誰か——が入っています。記憶は保管庫の中の2つのファイルです。あなたの「はい」がなければ何も入らず、すべての項目を読み、変更し、削除できます。

## 2つの置き場所

**常に含める**は、新しい会話すべてに入ります。短くしておいてください。2,000文字分の余地があり、バーでどのくらい埋まっているかが分かります。入りきらなくなった項目には**空きがないため含まれません**と表示されます——保存はされますが、一緒には送られません。項目は並んでいる順に含まれるので、いちばん大切なものは先頭に置いてください。順序はファイルで変更します。

**必要なときに参照**は、一緒には送られません。質問が以前AIに伝えたことに関係しそうなときは、AIがここを調べ、会話に**記憶の参照**と表示されます。ときどきしか必要にならないこと——ある取引先の条件や、ある決定とその理由——の置き場所です。

## 記憶を開く

デスクトップでは、AIタブで**記憶**を選びます。**スキル**の隣にあります。スマートフォンでは**会話 → 記憶**です。**設定 → AI・自動化**（保管庫側）からも開けます。**記憶を開く**が**スキルと記憶**にあります。

## 自分で項目を追加する

**新しい項目**で入力するのは3つです。テキスト（1項目につき1つのこと、最大500文字の1行）、置き場所（**常に含める**または**必要なときに参照**）、そして**この端末上のモデルのみ**にするかどうかです。クラウドのモデルに伝えたくないことには、これにチェックを入れてください。

項目の⋯ボタン（スマートフォンでは項目をタップ）から、**編集**、もう一方の置き場所への移動（**常に含める**または**必要なときだけ参照**）、**削除**を選べます。

## AIに覚えさせる

会話の中で「私は時間単位ではなく日単位で請求していることを覚えておいて」と言います。AIは項目の下書きを作りますが、自分で書き込むことは決してありません。回答の下に、**下書き · 記憶の項目**のカードが全文を表示します。置き場所を選んで**記憶する**を押すか、**破棄**を押します。まだ決めていない下書きは**保留中**に残り、記憶には待っている件数が表示されます。

「…のことは忘れて」も同じ流れです。カードには**下書き · 記憶から削除**と表示され、**削除する**を押すと項目が取り除かれます。何かが変わったとAIに伝えると、新しい文面がどの項目に取って代わるかが、カードの**置き換える項目**に表示されます。

## ルールは記憶ではありません

「いつもドイツ語で答えて」は、知っておくことではなく、行うことです。このようなルールは記憶には入りません。**保管庫の指示**（`AGENTS.md`）の1行になり、すべてのモデルが指示として受け取ります。追加するには、**ルールを追加**（**AIへのルール**にあります）を使うか、AIに頼みます。その場合、カードには**下書き · AIへのルール**と表示され、ボタンは**ルールとして追加**です。

すべての指示と同じく、このファイルは各端末で承認してはじめて、その端末で有効になります（[スキル](AI_Skills.md)を参照）。ファイルをすでに承認した端末で追加したルールは、その端末ではすぐに有効になります。ほかの端末では、先に確認を求められます。

## プライバシー

- 項目には、それぞれ独自のルールを付けられます: **クラウドのモデルには送らない**、**インターネットを使う会話には含めない**。この端末上のモデルには、すべての項目が渡されます。
- プライバシールールのあるノートを読んだ会話でAIが下書きした項目は、同じルールを引き継ぎます——カードには**この項目は、この会話の元になったノートのプライバシールールを引き継ぎます。** と表示されます。この端末にとどめるべきノートの内容が、記憶を通じてクラウドに届くことはありません。
- あなたの[プライバシールール](AI_Assistant.md)は、2つのファイルにも適用されます: `.agent/`のフォルダールールを設定すると、記憶全体がクラウドに送られなくなります。
- 送信の概要には、一緒に送られる項目の数を示す**記憶**の行があり、ルールで送られない項目は**送信しなかったもの**に数えられます。どの項目かが示されることはありません。
- AIにとって、項目は情報であって指示ではありません: 記憶の中の文が、AIに何かの権限を与えることはありません。
- 会話は、始まったときの記憶をそのまま使い続けます。削除した項目は、新しい会話には渡されません。すでに始まっている会話は、渡された内容をそのまま保ちます。

## オフにする

**この端末で記憶を使う**は、オフにするまでオンです。オフにすると、この端末での会話は記憶から何も受け取らず、記憶に何も追加しません。ファイルはそのままで、オンにするかオフにするかは端末ごとに決まります。

## 2つのファイル

`.agent/active_memory.md`（常に含める）と`.agent/MEMORY.md`（必要なときに参照）は、ごく普通のMarkdownファイルです。どの項目も箇条書きで、見出しが項目をグループにまとめます。Plainvaが項目について把握していることは、その後ろにあるコメントに書かれています:

```markdown
## Clients

- Harbour Studio pays within 14 days.
- I bill per day, not per hour. <!-- plainva: added=2026-10-09; by=assistant; source=Offer for Harbour Studio; deny=cloud -->
```

`added`と`by`は、項目がいつ追加されたか、そしてあなたが書いたのか下書きを受け入れたのかを表します。`source`は下書きの元になった会話の名前、`deny`は項目のルール（`cloud`、`web`）です。ファイルはどのエディターでも編集できます。Plainvaでは、**ファイルを開く**でどちらのファイルも開けます。

Plainvaは推測しません。コメントが壊れている項目には、コメントを直すか項目を追加し直すまで、**ルールを読み取れないため、どのモデルにも送られません**と表示されます。コメントや見えない文字に隠されたテキストは、決して送られません。その場合、項目には、省かれた隠れた部分がいくつあったかが表示されます。1つのファイルには、最大で2,000項目、256 KBまで保存できます。
