# 検索

最終更新: 2026-09-19

Plainvaは3つの検索方法を提供します: 保管庫全体を対象とする全文検索、ファイルを開くためのクイックスイッチャー、そしてノート内の検索と置換です。

## 保管庫全体の全文検索

サイドバー上部の検索欄では、保管庫全体のタイトルと内容を検索できます。ローカルの全文インデックス（SQLite FTS5）は保管庫を開くと作成され、ファイルの変更に応じて更新されます。検索はオフラインでも利用できます。

検索は入力するとすぐに反応します: 単語の前方一致（プレフィックス）で早くもヒットします（「Projec」で「Project plan」がヒットします）——Enterキーを押す必要はありません。フィールド右側の**X**をクリックすると現在の検索がクリアされます（または`Esc`を押します）。その後、サイドバーには通常のファイルツリーが再び表示されます。

検索結果には、一致箇所ごとに抜粋、見出しの階層、行番号が表示されます。行を開くと、その一致箇所が選択されます。同じノート内の複数の一致箇所も別々に表示されます。件数は読み込み済みの結果だけを示し、続きは追加で読み込めます。矢印キーで選択を移動し、Enterで開きます。読み込み中、結果なし、エラーを明示し、新しい検索では古い応答を破棄します。編集によって一致箇所を一意に特定できなくなった場合は通知します。同じ一致箇所をクイックスイッチャーとモバイル検索でも利用できます。スマートフォンで検索画面に戻ると、検索語、読み込み済みの結果、リストの位置が復元されます。検索結果は **関連度** 順です。検索欄の横の並べ替えボタン（スマートフォンでは検索画面のバー）で **最終更新**、**タイトル**、**パス** を選べます。続きを読み込んでも選んだ順序は保たれます。

検索フィールドは他のサイドバービューにも適用されます: **タグ**ではタグリストを、**ブックマーク**ではブックマークをフィルタリングします。

### 検索演算子

- `"exact phrase"` — 引用符で囲むと、その単語の並び順に正確に一致します。これは単一の単語に対する完全一致検索としても機能します: `"plan"`は「plan」にはヒットしますが「planning」にはヒットしません。
- `-term` — その用語を含むノートを除外します（フレーズでも機能します: `-"old version"`）。
- `path:folder` — パスにそのテキストを含むファイルのみを対象にします（例: `path:Projects`。スペースを含む場合: `path:"My Folder"`）。
- `tag:name` — そのタグを持つノートのみを対象にします。ネストされたタグも含まれます: `tag:project`は`#project/internal`にもヒットします。`tag:#project`という書き方でも機能します。
- 演算子は否定でき（`-path:Archive`、`-tag:done`）、検索語と自由に組み合わせられます: `plan tag:project -draft`。
- 複数の用語はAND条件で組み合わされます。用語内の`- ( ) : *`のような特殊文字は問題になりません——Plainvaは入力をそのまま文字どおりに扱います。

## クイックスイッチャー

`Ctrl+O`または`Ctrl+K`でクイックスイッチャーが開きます: 入力し、矢印キーでナビゲートし、`Enter`で開きます。何も入力していないときは、**最近使ったファイル**のリストが表示されます——現在のノート間を移動する最速の方法です。一致した項目は、新しいタブで直接開くこともできます（ダイアログのフッターに対応するキーが表示されます）。

一致判定はあいまい検索（ファジーマッチ）です: `prjplan`でも「Project Plan」がヒットします——文字が順番どおりに現れさえすればよく、単語の先頭にマッチした場合は優先度が上がります。そして、まだ存在しないノート名を入力した場合は、リストに**「{{name}}」を作成**と表示されます: `Enter`で（保管庫のルートに）即座に作成して開きます——名前を入力し、Enterを押し、書き始めるだけです。

名前の一致の下には、さらに**内容**というグループも表示されます: 入力に本文が一致するノートで、一致箇所がハイライトされた抜粋が表示されます。開くと、ノート内の一致箇所へ直接ジャンプします——サイドバーの検索と同様です。

## ノート内の検索と置換

`Ctrl+F`でエディターの検索バーが開きます（ライブプレビューとソースモードの両方で）。

- **検索**は`Enter`/**次へ**と**前へ**で一致箇所を移動し、**すべて**はすべての出現箇所をハイライトします。
- オプション: **大文字と小文字を区別**、**単語単位**、**正規表現**。
- **置換**: 個々の一致箇所を**置換**するか、**すべて置換**します。

### 保管庫全体で

`Ctrl/Cmd+Shift+F`（またはコマンドパレットの**Vault 全体で検索と置換**）を使うと、すべてのノートを一度に検索できます。検索語を入力して**検索**を押すと、一致箇所がノートごとにグループ化され、それぞれに文脈を示す1行が添えられて表示されます。置換後の文字列を入力し、除外したいノートのチェックを外してから**N 件のノートで置換**を押すと、残りのノートが書き換えられます——各ノートは安全に書き戻されるため（アトミックな書き込み＋バージョンのスナップショット）、古くなったプレビューが新しい内容を上書きしてしまうことはありません。ここでも大文字と小文字を区別・単語単位・正規表現のオプションが使え、正規表現モードでは置換後の文字列内で`$1`/`$2`の後方参照が利用できます。

各ヒットは 2 行で表示されます。**変更前** は該当箇所、**変更後** は結果です。正規表現では `$1` の後方参照が展開されるので、書き込む前に変更を確認できます。無効な式は空の一覧ではなく入力欄のそばで指摘され、該当なしの場合は空の状態が確認すべき点を示します。置換中は進行状況が表示され、**キャンセル** できます。すでに書き込まれたノートはそのまま残り、名前が示されます。スマートフォンでも各ヒットは同じ 2 行で表示されます。

**スマートフォンでも同じこと**が ヘッダーの虫めがね、続いて `>` を入力して **Vault 全体で検索と置換** から行えます。一致はノートごとにまとめられ、折りたたまれた状態で表示されるため、40 件一致する語であっても操作ボタンが埋もれません。ノートをタップすると中身を確認でき、触れてほしくないノートはチェックを外します。ボタンは自らの適用範囲を示します（**2 件のノートで置換**）。アプリを離れると実行中の置換は次のノートで停止し、すでに書き込まれたノートはそのまま残り、名前が示されます。

## タグ

サイドバービューの**タグ**は、保管庫内のすべての`#tags`をヒット数とともに一覧表示します。クリックすると**#tagを含むファイル**が表示されます。タグは本文（`#project`）でもFrontmatter（`tags: [project]`）でも機能します。サイドバーの検索フィールドは、タグリストもフィルタリングします。

ノートの中では、タグは小さなピルとして表示されます。書いているときも読んでいるときも同じで、テキスト自体は `#project/website` のままです。ピルをクリックすると（スマートフォンでは閲覧中のタップ）、そのタグを持つノートが開きます。何がタグとして数えられるかは、タグ一覧でもタスクでも名前変更でも同じです。行頭または空白の後の `#` に、文字、数字、`_`、`-`、`/` が続くものです。数字だけのものはタグではなく（`#42` は番号のまま）、コードやリンクの中にあるものもタグではありません。**設定 → アプリ → 外観** の **タグに色を付ける** は、各タグに名前から決まる色を付けます。入れ子のタグは最上位のタグと同じ色になります。この設定はこのデバイスのもので、ノートには何も保存されません。

**タグの名前を保管庫全体で変更**するには、**タグ**ビューでタグを右クリックし、新しい名前を入力します。Plainvaはそのタグをあらゆる場所で書き換えます——本文中（`#tag`とその`#tag/child`サブタグ）とFrontmatter（`tags:`）の両方です——影響を受ける各ノートは、同じ安全な仕組みで書き戻されます。名前を含んでいるだけの無関係なタグ（例えば`#area/tag`）はそのままです。

## ノート内のナビゲーション

右サイドバーの**アウトライン**は、アクティブなノートのすべての見出しを一覧表示します——クリックするとその場所にジャンプします。ノート間のジャンプには、**バックリンク**（誰がここにリンクしているか）とエディターの**戻る**/**進む**ボタンも役立ちます。
