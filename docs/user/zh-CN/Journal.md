# 日志

更新日期：2026-09-22

日志是无需打开笔记就能快速记下一件事的方式：一个想法、一通电话、当天的一句话。每个条目都是一行带有时间的普通列表文字——`- 14:05 路由器在地下室`——位于**今天的每日笔记**的一个标题下方。这里没有新的文件格式，也没有数据库：条目保存在你的每日笔记中，可以用任何编辑器读取，并且与Obsidian的日志类插件（Thino、Knomo）兼容。

## 撰写条目

一个输入框，一次**Enter**。Plainva会标注时间；你只需要输入文字。标签、链接和第二行都可以直接输入——文本就是普通的Markdown。

- **在桌面端：**`Ctrl+Shift+J`会从Plainva中的任何位置打开**日志条目**输入框。侧边栏的**＋**菜单、命令面板和通知区域的菜单（**日志条目**）中也有同一个输入框。`Enter`保存，`Shift+Enter`换行，`Esc`放弃。
- **在手机上：**圆形**＋**按钮提供**日志条目**；日志屏幕本身也有一个笔形按钮。长按应用图标同样提供**日志条目**——在Android上是应用快捷方式，在iOS上是快速操作。那里的`Enter`仍然只是换行；**保存条目**才会保存。
- **从分享面板（手机）：**选择Plainva并勾选**存入日志**——文字和链接会成为条目内容，分享的文件会进入附件文件夹并被嵌入。
- **带图片时：**手机上的输入框带有**添加照片**；在桌面端，你可以把剪贴板中的图片粘贴进输入框。图片会存放到附件所在的位置，并嵌入到条目中。

如果今天的每日笔记还不存在，它会在此过程中被自动创建——使用你的每日笔记模板，但不会提出模板中的问题。保存后，一条提示会显示**条目已保存**，并提供**撤销**。

输入框只做一件事：写日志条目。下方的**改为创建任务**会把已输入的内容交给[任务视图](Tasks.md)，在那里照常建立任务，并关闭输入框。标签**作为任务**是另一回事：它让条目留在日志里并加上复选框（`- [ ] 14:05 订购备件`），因此它也会出现在任务视图的**来自笔记**里。标签上的方框在你选中之前一直是空的。

## 日志视图

**打开日志**（桌面端的操作栏、手机上的**区域**，或命令面板）会把所有日期显示为一条信息流：最新的一天在最上面，同一天内最新的条目排在最前面。链接可以打开，标签显示为胶囊，嵌入的图片显示为预览，较长的条目会被折叠——点击**更多**展开。

- **搜索和筛选：**搜索框会在已加载的日期中查找；芯片**全部**、**仅任务**以及最常用的标签会缩小信息流的范围。点击条目中的一个标签即可按它筛选。
- **更早的日期：**Plainva会加载有条目的最近 14 天。**加载更早的内容**会取来下一段；**跳转到某一天**会打开日期选择，其中带有条目的日期会有标记，并会一直加载到你选中的那一天。
- 一天标题中的**打开笔记**会打开那篇每日笔记；点击一个条目则会在对应的那一行打开笔记。
- 任务条目的**复选框**可以直接在信息流中勾选。它们的行为与任务视图中相同，包括完成日期，以及重复任务的下一次出现。

每个条目都有一个菜单（桌面端右键点击或**⋯**；手机上**⋯**、长按或滑动）：**编辑**会原地修改文字并保留时间，**复制**会复制文字，**转换为任务**会加上复选框，**转换回条目**会将其移除，**在笔记中显示**会跳转到该行，**删除**会移除条目——随后的提示中带有**撤销**。

某一天的条目也会出现在你查看那一天的地方：桌面端右侧栏的**日志**区域（对应已打开的日记的日期，否则是今天），手机端则在**今天**屏幕上对应所选日期。在侧栏里它和其他区域一样：可以折叠、会记住状态、可以隐藏，并且默认是收起的。它的每一条只占一行：那里不做任何操作，每一行都从同一条边开始，任务在右侧用一个安静的标记表示，而不是复选框（打勾请在流里或笔记里完成）。标题里的铅笔会为这一天打开常规的**日志条目**输入框，**全部日期**则前往整条流。

## 条目是如何保存的

```markdown
## Journal

- 09:12 打电话给维修店 #客户
- [ ] 10:30 订购备件
- 14:05 路由器在地下室
  钥匙在贝格尔女士那里。
```

- 条目会追加在该区段的末尾，因此文件读起来是按时间顺序的；视图中则显示最新的在最上面。
- 标题在默认情况下是**Journal**，可以在**设置 → 仓库 → 内容与结构**（**日志标题**；手机上则在**设置 → 内容与结构**）中按仓库更改。它的级别并不重要。如果标题缺失，Plainva会在笔记末尾添加`## Journal`。更改这项设置不会重命名已有的标题。
- **一天结束于**（设置中的同一位置）把一天的分界往后移：设为 **04:00** 时，你在午夜到四点之间写的内容仍属于前一天 —— 条目会进入昨天的日记，并保留它真实的时间（`- 01:30 …`）。此时日志中的日期标题会显示**至 04:00**。这条分界仅适用于日记和日志，**不**适用于日历，也不适用于任务的截止日期：周三凌晨 01:30 的日程仍在周三。默认为**午夜**；该设置属于保险库，在所有设备上生效。
- **语音备忘**：输入框中的麦克风图标可以录音。录音时你能看到已用时间，并有两个出口：**丢弃**会舍弃这段录音，**附加**会将它写入附件文件夹并加到条目上。文件名带有日期和时间（`语音备忘 2026-09-22 1430.m4a`）。Plainva 在**首次**点击时才请求麦克风权限，不会在启动时请求；你不主动录音就不会录下任何内容，录音留在你的保险库中，不会发送到任何地方。
- Plainva也能读取`- 14:05:30 文字`（带秒）以及带复选框的条目，并会按你的笔记已经使用的方式延续列表（`-`、`*`或`+`，条目之间有没有空行都可以）。已有的行永远不会被重新格式化。
- 如果一处更改无法被安全地放置——比如该区段中的一个代码块从未闭合——就会被拒绝并显示一条消息，输入框会保留你的文字。

确切的格式参见[文件格式参考](File_Format_Reference.md)。

## 两台设备同时使用

如果两台设备在完成同步之前，都向同一篇每日笔记添加了条目，这**并不是冲突**：Plainva会按时间合并这些条目，两台设备的每一行都会保留。即使两台设备各自独立创建了当天的笔记，同样如此。对笔记的任何其他同时更改，仍会像以前一样谨慎处理（参见[同步兼容性](Sync_Compatibility.md)）。

## 全局快速记录（桌面端，可选）

在**设置 → 启动与行为 → 全局快速记录**下，你可以打开**用系统级快捷键随时随地记录**。这个快捷键——默认是`Ctrl+Alt+J`（macOS上是`Cmd+Option+J`）——随后会打开一个带有条目输入框的小窗口，即使另一个应用正在前台运行也是如此，只要Plainva在运行（包括在通知区域中）就可以使用。`Enter`会把条目写入Plainva中打开的仓库当天的每日笔记，并关闭窗口；`Esc`放弃。

- **更改**会记录一个新的快捷键：按下你想要的组合键，需要包含`Ctrl`、`Alt`或Windows/Command键。**恢复默认**会把默认值找回来。
- 如果另一个应用已经在使用这个快捷键，或者系统不接受它，Plainva会在开关下方说明，而不是留下一个毫无反应的快捷键。
- 在**Wayland**（Linux）下，系统不会为应用提供系统级快捷键；Plainva会说明这一点，并且不会注册任何内容。通知区域中的条目和`Ctrl+Shift+J`会打开同一个输入框。
- 这个快捷键属于设备本身，不属于设置配置文件。
