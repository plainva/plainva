# 连接AI应用（测试版）

更新日期：2026-10-07

你电脑上的AI应用——Claude Code、Claude Desktop、Cursor、VS Code以及其他支持Model Context Protocol（MCP）的应用——可以通过Plainva读取你的仓库：搜索它，读取笔记及其段落、大纲、反向链接、数据库、任务和最近的笔记，并在Plainva中打开笔记。它们自己不会更改任何内容：经你允许的应用可以提出修改建议，这些建议会一直等待，直到你做出决定（见下文）。这是实验性AI功能的一部分，只在桌面端可用。

相反的方向——由Plainva的助手使用你自己连接的服务器所提供的工具——见[AI助手](AI_Assistant.md)中的**外部工具（MCP）**。

第三种方式——由Plainva在仓库的文件夹中启动其他厂商的AI智能体，并在AI标签页中显示它的会话——见[外部智能体](External_Agents.md)。

## 工作原理

Plainva在应用旁边附带一个小型辅助程序`plainva-mcp`。AI应用启动它，辅助程序再通过此电脑的私有通道连接正在运行的Plainva——在Windows上是命名管道，在macOS和Linux上是私有文件夹中的套接字。从不打开任何网络端口。Plainva必须在运行并打开了仓库；否则应用会收到明确的提示。

## 开启

1. 打开**设置 → AI与自动化**，开启**在此设备上使用AI**。
2. 开启**允许此电脑上的AI应用读取这个仓库**。
3. 设置应用（见下文）。第一次连接时，Plainva会询问这是哪个应用、由哪个程序启动，以及它可以读取哪些文件夹。默认什么都没有勾选：选择文件夹或**整个仓库**，然后点**允许**。点**拒绝**会拒绝该应用，并且Plainva在十分钟内不会再询问它。文件夹下方是**可以提出修改建议**，不勾选就保持关闭；它允许什么，见下文。

应用会把一个密钥保存在系统钥匙串中，供下次使用。文件夹按应用和仓库分别授权：在另一个仓库中，应用会再次询问。

## 设置应用

- **Claude Code：** 从设置中复制**Claude Code的命令**，并在终端中运行。
- **Claude Desktop：** **创建安装包…**会写出一个`plainva.mcpb`文件；打开它，Claude Desktop就会安装Plainva。
- **其他应用（JSON）：** 复制配置，并添加到应用的MCP设置中，例如Cursor的`mcp.json`。

## 应用能看到什么

只有你允许的文件夹，而且只有你的隐私规则允许发送给可以访问互联网的云端模型的内容——应用被视为这样的模型，因为Plainva看不到它如何处理读到的内容：带有`cloud: deny`或`web: deny`的笔记，或位于带有其中一条规则的文件夹中的笔记，对应用来说并不存在——既看不到正文，也看不到标题——；指向它们的链接会被隐去，日志中的地点从不发送。Plainva自己的文件夹（`.plainva`、`.agent`）和规则本身永远无法读取。请求和回答中的每个路径都会检查两次：在应用窗口中，以及在Plainva的原生部分中。

设置中会列出已允许的应用及其文件夹和最近的请求。**移除**会在所有仓库中收回某个应用的权限。这会立即生效，对当时已连接的应用也是如此。

除了工具之外，Plainva还以应用的语言把三个技能作为提示词提供：`daily-orientation`、`weekly-review`和会询问项目名称的`project-status`。支持提示词的应用会把它们列在自己的命令中。

## 让应用提出修改建议

允许读取绝不等于允许写入。应用是否还可以提出修改建议，是一个单独的回答：首次连接时询问中的**可以提出修改建议**，或之后设置中的开关**…可以提出修改建议**——按应用、按仓库分别设置，在你开启之前保持关闭。它从应用的下一次请求起生效；新增的工具会在应用重新连接后显示。

获得允许的应用会多出六个工具，但它们都不会更改仓库：

- **对笔记的修改**（正文或某个属性）会成为笔记页边的建议，署名为应用的名称和“（AI应用）”。你可以在那里逐条采纳或拒绝，与其他建议一样（参见[评论与建议](Comments_and_Suggestions.md)）。
- **新笔记**会成为AI标签页中**待处理**下的草稿。在那里选择**创建**后，笔记才会存在。
- **重命名、移动和删除**会先询问。Plainva会在自己的窗口中显示将会发生什么（重命名时还会显示链接会随之更新的笔记），应用则显示Plainva正在等待的提示。只有在Plainva中点**允许**并且应用继续之后，Plainva才会按照你手动操作时的方式执行；应用只会得知是否已执行。删除时，Plainva随后会打开自己的删除对话框，在你确认之前不会有任何内容消失。无法显示这类提示的应用不会获得这三个工具。

应用带入的网址会以不会被打开或加载的形式写入（`https[://]…`），与助手相同。笔记自身的隐私规则（`plainva.ai`）不能由应用设置，在加密的工作区中也不会提出建议、起草或计划。设置中的**最近的请求**会说明每个请求的结果，包括Plainva曾向你询问，或你已拒绝。

## 限制

- 仅限桌面端：手机上不运行这类应用，而且iOS和Android都不允许一个应用为另一个应用提供私有通道。
- 浏览器中的ChatGPT和claude.ai无法访问它：它们只能连接互联网上的服务器，而Plainva并不运行这样的服务器。
- 应用不会自行更改仓库：它写入的内容会作为建议或草稿等待，重命名、移动或删除需要你在Plainva中同意。
