# 移动应用

更新日期：2026-07-26

Plainva也提供Android和iOS版应用。它使用与桌面版相同的Markdown文件、相同的**OKF**格式以及相同的同步引擎——你的仓库在两端保持完全一致。

## 布局

- **底部栏：** **三到五个**你自选的区域——不再有固定的**更多**标签，空出来的位置全部属于你选择的区域。
- 通过**区域面板**，**每个区域**（笔记、今天、标签、书签、日历、数据库、关系图）都可以随时一触即达：可以点击顶部栏中**标题旁的▾**，也可以**长按底部栏**。面板会标出当前所在的区域，底部还能直接进入**调整导航栏…**。
- **配置导航栏：** **设置** → **导航栏**。用**−**/**+**设置导航栏显示的区域数量（3–5个，带实时预览），再用**拖动手柄**排列列表：排在最前面的几项组成导航栏（以边框标出），把某一项向上拖动即可将其纳入导航栏。不会隐藏任何内容——不在导航栏中的区域仍可通过区域面板访问。如果你当前所在的区域被移出导航栏，应用会自动切换到第一个仍在栏中的区域。
- **＋**以圆形按钮的形式悬浮在底部栏上方，点击即可打开快速新建：笔记、每日笔记、文件夹、数据库、“从模板…”。
- **顶部栏：** 带**▾**的标题（点击打开区域面板）、搜索和**设置**（⋮）；主页还会额外显示“最近”和你的书签。
- **设置：** ⋮ 按钮会先打开区域列表（类似桌面版设置的左侧）——轻点即可打开相应页面。最上方的**当前仓库**会带你进入仓库管理：切换仓库（勾选标记 = 当前）、**创建 Vault**和**连接云端仓库**。

## 阅读和编辑笔记

笔记以**渲染后的只读**状态打开；右上角的笔形图标可切换到编辑状态（键盘上方会出现工具栏：格式、列表、内部链接、斜杠命令、插入照片）。`![[笔记]]`嵌入会以可点击的预览卡片形式呈现。

点击顶栏中的**笔记详情**按钮（位于书签和 ⋮ 菜单之间）会打开笔记的上下文面板：属性（可直接编辑）、反向链接、大纲、关系图，以及**版本历史**——每次编辑都会自动生成快照，你可以查看、比较并恢复。Markdown源码和笔记内搜索位于 ⋮ 菜单中。

## 数据库（`.base`）

`.base`数据库的使用方式与桌面版相同：每一种视图（表格、列表、画廊、看板、日历、时间轴）、按类型编辑单元格、长按移动看板卡片。**配置**用于管理视图、列、筛选条件（包括分组）、排序和属性。关联模式（目标数据库、数量限制）仍需在桌面版中维护。

**便签板**视图会以两列便签卡片的形式显示笔记：轻点可打开笔记，长按会显示操作菜单（固定、标签、颜色、删除），长按后拖动可重新排序，复选框可以直接在卡片上勾选。顶部的输入框用于记录一篇新笔记。提示：将数据库指向你的收件箱文件夹（**设置** → **内容与结构**），这样＋快捷新建的笔记以及从其他应用分享过来的文本就会直接出现在便签板上。

## 日历与活动

**日历**（底部标签或通过"更多"）以月视图网格显示你的每日笔记。右上角的时钟图标可打开**活动日历**，提供**日**、**3天**和**日程**视图——你连接的日历与桌面版使用相同的账户模型。点击某个活动会显示其详情；如果是邀请，你可以直接在此**接受**、标记为**待定**或**拒绝**。

在活动日历中点击齿轮图标即可管理账户：在设备上使用应用专用密码连接**CalDAV**（例如Fastmail、Nextcloud、iCloud）；Google和Microsoft则通过浏览器登录连接。你可以按账户显示或隐藏单个日历。

**登录以设备为单位。** 会同步的是你账户的*设置*，绝不会同步登录状态本身——这是刻意为之：凭据不应离开设备。因此，通过设置同步添加的账户会出现在列表中，但会带有**登录**标记，下方还会说明你该做什么。只要此设备上还没有任何账户登录，日历就会就地说明这一点，而不是简单地保持空白，并通过**在此设备上登录**带你进入账户列表。已登录的账户会显示为**活跃**。

## 电子邮件

在**设置 → 电子邮件**中，你可以通过浏览器登录直接连接 **Microsoft 邮箱**（Outlook.com、Microsoft 365），无需应用专用密码。与日历一样，登录按设备生效。

之后，你可以通过标题旁的 ▾ 把**电子邮件**作为独立区域打开，也可放入导航栏。标题下方的一行显示文件夹、未读数量和账户，点按可打开文件夹选择。点按邮件即可阅读；**保存为笔记**会把它存入保险库的 **Mail** 文件夹（重复保存会打开同一条笔记）。远程图片默认被拦截，直到你为该邮件放行——加载的图片会让发件人知道你何时何地阅读了邮件。

**IMAP 邮箱在手机上还不能使用。** 它们需要与邮件服务器直接连接，该功能仍在开发中。通过设置同步从桌面端过来的 IMAP 邮箱会出现在列表中并在原处说明这一点——请暂时在桌面端使用。

## 同步

在**设置**（⋮）中，**当前仓库**会带你进入仓库管理；在那里连接云存储（WebDAV / Nextcloud、Google Drive、OneDrive、Dropbox、S3）。**连接云端仓库**会把已有的云端仓库带到设备上；**创建 Vault**会先问**在此设备上**还是**在在线服务中**，然后选择起始结构（空白或PARA等模板）——在在线路径下，接下来会进行连接，云端的目标文件夹可以在选取面板中通过**新建文件夹**新建，结构会在首次同步时上传。首次启动（“连接云端仓库”）提供的是同样的选择——已有或新建云端仓库。每个连接都会在设备上拥有各自独立的仓库。仓库页面会显示状态、进度、待处理的传输，并提供**导出仓库**（通过分享面板生成ZIP）。

此仓库检查远端变更的频率也在同一页面设置（**同步间隔**，最少 5 秒）——本地保存无论如何都会立即上传。使用 Google Drive、OneDrive、Dropbox 和 S3 时，**云端文件夹**之后也可以更改；WebDAV 的文件夹包含在服务器地址中，需要重新连接。若设置同步已加密，还可以开启**每次启动都询问密码短语**：密钥便不会保存在本机。此外，**安全与共享**现在明确说明加密工作区仍处于实验阶段、尚未经过独立审计——请妥善保管恢复文件和恢复码。

仓库页面还会以状态清晰的卡片（而不是一个孤零零的按钮）来说明你的**设置**是否会跟随你：

- **未同步**：此仓库的设置同步处于关闭状态。请在桌面端开启它。
- **尚未加密**：此仓库还没有同步密码短语。你现在可以**在手机上**设置一个：向导会显示恢复码，并让你把其中随机选出的两组重新输入一遍，之后才会写入任何内容。如果云端已经存在密码短语，手机会告诉你，并且绝不会再创建第二个——那样会把所有其他设备都锁在外面。
- **此设备尚未解锁**：你的设置以加密形式存储在云端。请输入设置此功能时选择的密码短语——可以在桌面端，也可以就在手机上；此设备会用它一次性解锁这些设置。
- **正在同步**：此设备已解锁；文件夹、视图和备份规则会与你的其他设备保持一致。

每张卡片还会说明哪些内容*不会*跟随：登录状态始终只保留在设备上（参见[日历与活动](#日历与活动)）。

**设置** → **安全与共享**会说明该连接的真实状态；对于普通云仓库，可以直接在手机上设置加密工作区（身份 → 恢复文件与代码 → 激活）。没有云连接时没有需要加密的内容，该区域也会这样说明。

## 安全保障

快照（版本历史）、草稿日志（发生崩溃后，笔记会提供你最后未保存的状态）以及带对比视图的冲突副本，共同保护你的数据。保留策略可在**设置** → **备份与版本历史**中配置。

## 分享与快捷方式

在 Android 和 iOS 上，共享的文本和 URL 会成为收件箱文件夹中的新笔记；图片和文件会作为附件导入（每个文件最多 25 MB）。在 Android 上，长按应用图标还可使用**新笔记**和**今天**快捷方式。仓库页面可开启**同步设置**，并用密码短语安全地解锁或锁定加密仓库。

## 文件夹、照片和日历

浮动的**加号**按钮在嵌套文件夹中仍然可用，所有快速操作都会在当前打开的文件夹中创建内容。文件夹标题栏中的**三点菜单**会打开设置；新文件夹通过**加号**按钮创建。

编辑器中的照片按钮现在提供**拍摄照片**或**从照片库选择**，会保留插入位置，并明确显示权限或文件错误。

**日历**现在会直接打开已连接提供商的日历。日记仍位于独立的**今天**视图中；旧的本地月历中间页已被移除，现有笔记和日历数据不会更改。
