# 外部智能体（测试版）

更新日期：2026-10-07

外部智能体是其他厂商的AI程序——由你自己安装在电脑上、并用你自己的订阅或密钥自行登录的智能体。Plainva可以在仓库的文件夹中启动这样的智能体，并在AI标签页中显示它的会话。这是实验性AI功能的一部分，只在桌面端可用。

外部智能体不是Plainva的助手。[AI助手](AI_Assistant.md)只发送概览中给你看过的内容，绝不发送你的隐私规则拦下的内容。智能体则自行读取、自行发送。本页说明在这样的会话中Plainva能控制什么——以及不能控制什么。

## Plainva不能控制的

- **程序本身。** 智能体是别人的程序。它以你的权限运行在这台电脑上、仓库的文件夹里，没有任何隔离：凡是你能读取和更改的，它都能读取和更改。
- **它读取和发送的内容。** 它自行读取文件——包括你排除在云端之外的笔记——并把它选中的内容发送给它自己的服务。你的隐私规则和发送前的概览都管不到它，它发送之前也不会有任何询问。
- **它自行写入的内容。** 智能体自行做出的更改会立即进入仓库，不经过建议。智能体报告这样的更改时，会话会告诉你；它没有报告的更改，Plainva看不到。
- **它的登录。** 智能体自行登录。Plainva从不看到它的凭据，也不保存任何凭据。

只在内容可以到达智能体服务的仓库中启动智能体。

## Plainva能控制的

- **Plainva自己的工具。** 在开启了**允许此电脑上的AI应用读取这个仓库**的情况下，Plainva的工具会提供给智能体——与[连接AI应用](Connect_AI_Apps.md)中每个应用得到的相同：只有你授予的文件夹，绝不包含排除在云端或互联网之外的笔记，并且只读——除非你在那里允许它提出修改建议。
- **智能体请求Plainva读取的内容。** 排除在云端之外的笔记和Plainva自己的文件夹不会交出。智能体会得知这一点，你也会。
- **智能体请求Plainva写入的内容。** 什么都不会写入。对笔记的更改会变成以智能体名义提出的一轮建议，新笔记则等到你创建它为止。
- **没有终端。** Plainva不向智能体提供自己的终端。

## 添加智能体

1. 按照厂商的说明自己安装智能体，并在它自己的程序中登录。
2. 打开**设置 → AI与自动化**（应用部分）。在**外部智能体**下，**已在这台电脑上找到**标出Plainva按名称认识并发现已安装的智能体；点**添加**即可加入其中一个。对于其他任何支持Agent Client Protocol的程序，在**其他智能体**下选择**添加智能体…**，并填写**名称**、**程序**和**参数，每行一个**。
3. 在记住之前，系统会再次显示完整的命令。

Plainva不安装任何智能体，也不下载任何智能体。它直接启动你确认过的那个程序，不经过shell。命令保存在此设备上，绝不保存在仓库中。**移除**会让Plainva忘记如何启动智能体；程序本身及其登录保持原样。

## 开始会话

打开AI标签页并选择**智能体**。在启动任何东西之前，**启动 ⟨智能体⟩ 之前**会列出智能体自行做的事和Plainva控制的事，并说明是否会提供Plainva的工具。**开始会话**会在仓库的文件夹中启动智能体的程序。自Plainva打开以来第一次在某个仓库中启动智能体时，系统会再次询问，并显示文件夹和完整的命令。

同一时间只运行一个会话，它属于启动它的那个仓库：**结束会话**会停止智能体的程序，关闭仓库或Plainva也一样。在它运行期间，会话的第一行会说明智能体是谁，以及你的隐私规则对它不适用。在加密工作区中不会启动任何智能体。

## 登录

尚未登录的智能体会说明这一点，会话会显示**⟨智能体⟩ 要求登录**以及智能体给出的登录方式。视智能体而定，选择其中一种会打开一个运行智能体自己程序的终端窗口，或者由智能体自行带你去登录。Plainva会等待，然后重新启动智能体。在无法打开终端的地方，Plainva会显示需要在你自己的终端中运行的命令；之后选择**重试**。Plainva看不到登录的任何内容。

## 在会话中

输入你希望智能体做的事。你打开的笔记会被告知给智能体——是它的名称和位置，而不是正文——除非你在输入框上方把它移除；你排除在云端之外的笔记绝不会被告知。会话会显示智能体说的话、它的计划和它的每一个步骤，以及它提到的仓库中的文件。

当智能体需要你许可某个步骤时，**⟨智能体⟩ 的询问**会把它显示出来。文字是智能体自己的，选项也是智能体提供的——**允许**、**始终允许**、**拒绝**、**始终拒绝**。你的回答只发给智能体：得到许可之后它做什么是它自己的事，而“始终”是由智能体而不是Plainva来遵守的承诺。

**停止**会结束智能体正在处理的回答。

## 智能体写入的内容

**经由Plainva。** 智能体交给Plainva的更改绝不会写入笔记。智能体的回答结束后，它更改过的每篇笔记都会带上一轮建议，署名为**⟨名称⟩（外部智能体）**：在**建议**下，你可以逐条或整轮接受或拒绝，就像别人提出的一轮建议一样。尚不存在的笔记会出现在**智能体写的新笔记**下。**创建**会写入它——带有`generated`标记，作者为智能体——**放弃**则丢弃它。智能体带来的网址会以不会被打开或加载的方式写入（`https[://]…`）。

Plainva并不接受一切：只接受Markdown笔记，只接受正文而不接受属性，不接受带有AI规则或信任字段的笔记，不接受任何排除在云端之外的内容，并且一次对一篇笔记的更改不超过150处。它没有接受的内容，会话会说明，智能体也会得知。

**自行写入。** 和任何程序一样，智能体也可以自行写入文件。当它报告这样的更改时，会话会显示**智能体自行更改了 ⟨笔记⟩：更改未经建议，已在仓库中。**智能体走哪条路，Plainva无法保证：这取决于智能体及其配置方式。在设置中，每个智能体都会显示这台电脑上最近一次的记录——有多少更改经由Plainva，有多少是它自行写入的。

## Plainva保留的内容

- **在此设备上：** 你确认过的命令、你给智能体起的名称，以及关于其更改的最近一次记录——保存在Plainva自己的数据中，绝不在仓库里。
- **每个仓库：** **此仓库中最近的会话**会列出会话在何时进行、使用了哪个智能体，以及有多少条消息、多少更改经由Plainva、多少是它自行写入的——绝不记录说了什么。
- **不保留会话本身：** 会话关闭后，你和智能体说过的话就消失了。智能体在它那一侧保留什么，是智能体自己的事。

如果智能体的程序自行结束，会话会说明，**显示它最后的输出**会显示程序最后写出的内容。

## 限制

- 仅限桌面端，并且仅在主窗口中。手机上有Plainva自己的助手。
- 不能在加密工作区中使用。
- 同一时间一个会话，没有历史记录：已结束的会话无法再次打开。
- 无法在Plainva中选择智能体自己的模式、模型和命令，也无法向它发送图片。
- 到目前为止，这只用Plainva自己的测试智能体试过。哪些智能体能在这里工作，哪些会把更改交给Plainva，要试过才知道——欢迎反馈。
