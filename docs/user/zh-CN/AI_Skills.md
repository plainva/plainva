# 技能（测试版）

更新日期：2026-10-01

技能是一组用于重复性工作的指令：准备会议、整理任务、每周回顾。Plainva自带十个技能，你也可以编写自己的技能。技能使用开放的Agent Skills格式（一个包含 `SKILL.md` 的文件夹），因此也能在其他读取该格式的AI应用中使用。

## 使用技能

一键即可启动技能：在空白对话中点击标签（最常用的三个），在AI标签页的**技能**下，在手机上的**对话 → 技能**中，或从命令面板启动。之后对话会使用该技能：它的指令随之发送，并且只使用该技能列出的工具和文件夹。

你也可以直接提问。在每个对话中，AI都知道你已启用技能的名称和描述，并会在问题匹配时加载其中一个——说一句“为我的下一次会议做准备”就够了。

## Plainva自带的技能

| 技能 | 作用 |
|---|---|
| **今日概览** | 今天的重点：到期的任务、日程以及你最近在做的事。 |
| **每周回顾** | 过去七天和即将到来的一周，并给出三条建议。 |
| **项目状态** | 项目的目标、进展、待办事项和下一步。 |
| **会议准备** | 根据以前的笔记和未决事项准备会议，或在会后进行整理。 |
| **任务梳理** | 整理你未完成的任务：现在做什么、什么可以等、什么可以放弃。 |
| **写作与修改** | 总结、缩短或改写笔记，作为你可以直接采用的文本。 |
| **知识维护** | 找出内容重复、已经过时或没有任何关联的笔记。 |
| **链接整理** | 检查笔记中的链接：指向不存在之处的、缺少的、单向的。 |
| **隐私检查** | 找出笔记中应留在本设备上的内容，并建议一条规则。 |
| **反思** | 和你一起回顾一天或一周的笔记——态度温和，从不做诊断。 |

它们都只读取：不会更改笔记、发送任何内容或访问互联网。隐私检查和反思适用于本设备上的模型；使用云端模型时，发送概览会提示这一点。你可以在**技能**中关闭任意技能——该开关对本设备上的这个仓库有效。**创建自己的版本**会把自带技能复制到你的仓库中，你可以在那里修改。

## 你自己的技能

**新技能**会要求填写名称、描述（AI根据描述选择技能）和指令。Plainva会把它们写入你仓库中的 `.agent/skills/<名称>/SKILL.md`，它们会像任何笔记一样随仓库同步。**编辑**会像打开笔记一样打开该文件。

**导入…**接受 `.zip` 或 `.skill` 文件形式的技能。在写入任何内容之前，Plainva会进行检查：格式中恰好有一个技能、没有离开其文件夹的路径、大小限制。它还会列出许可证、它不会运行的脚本以及它没有的工具。

## 未经你批准，什么都不会运行

仓库中新到达或已更改的技能（通过同步、导入，或在本设备或其他设备上的编辑）在你**于此设备上**批准之前不会运行。这类技能会显示在**技能**顶部的**等待你的批准**中，以及**设置 → AI与自动化**（仓库部分）中。**检查并批准**会显示该技能可以做什么、自你上次批准以来的变化、它的指令、文件以及所在位置。批准只对这一版本有效；任何更改都会使其失效。批准保存在本设备上，从不保存在仓库中。

仓库顶层的 `AGENTS.md` 也是如此：批准后，它的常设指令会加入每个新对话。技能和 `AGENTS.md` 都不能解除你的隐私规则，技能获得的权限也永远不会超过对话本身——它只能收窄范围。

## 发送给提供商的内容

发送概览会在**指令**下列出随请求发送的内容：对话的技能、AI可以加载的技能列表以及 `AGENTS.md`。当仓库中的指令首次发送到云端时，概览会再次出现。技能中的不可见字符永远不会到达模型。

## 测试版的限制

技能不运行脚本，需要网络或邮件的技能会在以后推出。你自己的技能不会提供给通过MCP服务器连接的AI应用；只有Plainva自带的技能会被提供。
